My interests sit at the intersection of **AI, data, geospatial systems, automation, optimisation and product engineering**. I like working across the stack—from shaping an idea and designing an interface to building the backend, testing edge cases and shipping the result.

I'm early in my engineering journey, so I'm deliberately optimising for **real projects, open-source contribution, strong fundamentals and continuous improvement**.

## How I work

**01 · Understand** → clarify the problem and constraints  
**02 · Design** → choose a simple architecture and useful interface  
**03 · Build** → implement the smallest version that proves the idea  
**04 · Test** → find failure modes and edge cases  
**05 · Refine** → improve performance, UX and maintainability  
**06 · Ship** → document it and make it useful

I value **clarity over cleverness, reproducibility over guesswork and useful software over feature count**.
