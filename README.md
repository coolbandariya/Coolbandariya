## How I work

<div align="center">

| 01 · DISCOVER | 02 · MODEL | 03 · BUILD | 04 · TEST | 05 · VERIFY | 06 · SHIP |
|:---:|:---:|:---:|:---:|:---:|:---:|
| Understand the problem | Define boundaries | Build the workflow | Test failure paths | Check the evidence | Deliver clearly |

</div>

I care about clear system boundaries, useful interfaces, failure-path testing, and honest status labels. I distinguish prototypes, simulated data, and connected live integrations instead of presenting a working demo as proven real-world impact.
