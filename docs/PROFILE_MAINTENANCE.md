# Profile README maintenance

The profile README is a concise index of work, not a substitute for the repositories themselves.

## Keeping it accurate
- Link only to repositories that are public and maintained under the expected name.
- Describe prototypes, simulations, and demo integrations as such.
- Keep the technology map tied to tools present in project files or documentation.
- Update selected projects when their purpose or implementation changes.
- Remove stale claims, broken images, and third-party widgets that no longer render reliably.

## Visual and accessibility checks
- Preview the README in GitHub light and dark themes.
- Check that headings and anchor links work.
- Give meaningful alt text to informative images and avoid relying on color alone.
- Keep animated elements limited and ensure the text remains understandable if external image services are unavailable.

## Contribution graph note
A README edit is useful documentation work, but a commit appears on the profile graph only when GitHub's contribution requirements are met. Confirm the commit author email is linked to the account and allow time for the graph to refresh.
